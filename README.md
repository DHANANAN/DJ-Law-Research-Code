## Auto deploy (Netlify)

This repository is configured for auto-deploy to Netlify on push to `main`.

Add these GitHub repository secrets:

- `NETLIFY_AUTH_TOKEN`: Netlify personal access token
- `NETLIFY_SITE_ID`: Site ID for `djlexfolio.netlify.app`
